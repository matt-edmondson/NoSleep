A cross-platform .NET tool that stops a machine from sleeping, dimming, or locking its display while it runs. Installs as the `nosleep` global tool and puts a system tray icon on Windows, macOS, and Linux so keep-awake can be toggled without touching a terminal. Uses native inhibitors on every platform - SetThreadExecutionState on Windows, IOKit power assertions on macOS, and logind or GNOME session inhibitors on Linux - with a headless console mode and an optional duration for servers, CI agents, and scripts.
